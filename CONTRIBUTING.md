# Contributing

Welcome! DiffMod is a project ran by the community, for the community.

- Ask questions and share your ideas in [Discussions](https://github.com/diffmod/spec/discussions).
- Report issues in the [issues tab](https://github.com/diffmod/spec/issues).
- Get news in our [Discord](https://discord.gg/usmu4RmvCc)
- Pull requests are welcome for any change.
  For bigger changes, preferably start a discussion first.

The spec is currently still a draft, so a breaking changes are still acceptable.
Edit `spec/v1.md`, then make the same change in `site/spec/index.html`.

Especially welcome are contributions regarding website text or layout improvements, and improving spec clarity.
Also we're looking for community manager to help manage Discord, let us know if you're interested.

AI/LLM contributions are welcome, with some light rules to make everyone's life easier:
* Self-review before you send it our way.
* Communicate with your own words, do not be a "meat proxy".

Contributions are under the [repo license](README.md#license).
